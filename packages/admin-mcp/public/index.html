Context7 Admin MCP

A remote MCP server to manage Context7 from Claude Code, Cursor, VS Code and other MCP clients: teamspace members, libraries, rules and policies, usage, Docs7 sites and Ask sites.

Endpoint

https://admin.mcp.context7.com/mcp

Add it to Claude Code

claude mcp add --scope user --transport http context7-admin https://admin.mcp.context7.com/mcp

Then run /mcp and sign in with your Context7 account.

Other clients

{
  "mcpServers": {
    "context7-admin": {
      "type": "http",
      "url": "https://admin.mcp.context7.com/mcp"
    }
  }
}

API key (CI and scripts)

Send Authorization: Bearer ctx7sk-… with a key created in the dashboard with Management access turned on. A key works on its own teamspace only.

Good to know

  • One sign-in reaches every teamspace you are a member of, with your role in each.
  • Remove and delete actions are marked destructive, so your client asks you first. Turn tools off or make them ask in your client's settings.
  • Billing, plans, API keys and SSO stay in the dashboard.
  • For documentation lookup, use the Context7 MCP server.
