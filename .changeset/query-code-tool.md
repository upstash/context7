Add the `query-code` MCP tool and the `ctx7 code` command. They find definitions, references, the public API outline, and exact text in a library's source code at the version its docs describe. The MCP tool is off by default: enable it with `--query-code` or `CONTEXT7_QUERY_CODE=1`.
