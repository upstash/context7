Add `@upstash/context7-opencode`, the official Context7 plugin for OpenCode. Installing it registers the hosted Context7 MCP server, the `context7-mcp` skill, a `docs-researcher` subagent, and the `/context7-docs` command. Authentication defaults to OAuth and falls back to `CONTEXT7_API_KEY` or an `apiKey` plugin option.
