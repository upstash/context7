Add `@upstash/context7-opencode`, the official Context7 plugin for OpenCode. Installing it registers the Context7 MCP server, the `context7-mcp` skill, and a `docs-researcher` subagent. The server runs over stdio, and picks up an API key from `CONTEXT7_API_KEY` or an `apiKey` plugin option.
