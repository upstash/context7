Most of Context7 is free. The Free plan covers the MCP server, the CLI, the Search API, every public library, library owner tools, [Context7 Ask](/ask/overview), and [Docs7 Free](/docs7/plans). Pay only for private repositories, teamspaces, and API calls above the included amount.

See the current prices on the [plans page](https://context7.com/plans).

## Free for everyone

With a free account and an [API key](/howto/api-keys), you get:

- **1,000 API calls each month** for the MCP server, the [CLI](/clients/cli), the [Search API](/search-api), and the [REST API](/api-guide)
- **Every public library** on Context7, and [adding new public libraries](/adding-libraries)
- **Library owner tools**: [claim your library](/howto/claiming-libraries), configure it with `context7.json`, [apply for verification](/howto/verification), and add the [chat widget](/howto/chat-widget) to your site
- **Access control**: [policies](/howto/policies) that filter the sources and libraries your requests use, and [OAuth](/howto/oauth) for MCP clients
- **[Context7 Ask](/ask/overview)**: an ask endpoint for up to three websites, with no charge for questions or answers
- **[Docs7 Free](/docs7/plans)**: up to three hosted documentation sites with a custom domain, preview deployments, analytics, and limited use of the Context7 Agent, PR reviews, and the AI assistant

When a Free account uses all 1,000 calls, requests stop until the next month. Each day until then, the account gets 20 bonus calls.

## Plan comparison

| Feature | Free | Pro | Enterprise |
| --- | --- | --- | --- |
| Price | $0 | $10 per seat / month | Custom |
| Included API calls | 1,000 / month | 2,000 / seat / month | 2,000 / seat / month |
| Additional API calls | Not available | $5 per 1,000 | $5 per 1,000 |
| Public libraries | ✓ | ✓ | ✓ |
| Search API | ✓ | ✓ | ✓ |
| Library owner tools | ✓ | ✓ | ✓ |
| Policies and OAuth | ✓ | ✓ | ✓ |
| Context7 Ask sites | 3 | No limit | No limit |
| [Private repositories](/howto/private-sources) | — | $5 per 1M parsed tokens | $5 per 1M parsed tokens |
| [Teamspaces](/howto/teamspace) | — | Up to 10 members | Up to 5,000 members |
| [Teamspace rules](/howto/rules) | — | ✓ | ✓ |
| SOC 2, SSO (SAML / OIDC) | — | — | ✓ |
| [Self-hosted deployment](/enterprise/on-premise) | — | — | ✓ |
| Dedicated support | — | — | ✓ |

Each API call is one Search API or context request. Search API calls have no separate price.

Pro and Enterprise accounts are never blocked when they use their included calls. Each seat has its own allowance; unused calls do not move to other seats.

Docs7 has its own plans. See [Docs7 plans](/docs7/plans).

## Enterprise

Teamspaces with up to 50 members can activate Enterprise from the plans page. For larger teamspaces, annual contracts, or a self-hosted deployment, contact [context7@upstash.com](mailto:context7@upstash.com). See [Enterprise](/enterprise).
