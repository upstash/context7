---
title: Installation
description: Add Context7 to your coding agent. It gives the agent current docs for the libraries you use.
---

import { ClaudeIcon, CursorIcon, OpenAIIcon, VSCodeIcon } from "/snippets/agent-icons.jsx";

<Tabs>
  <Tab title="Claude" icon={<ClaudeIcon />}>
    <Card title="Add to Claude" icon={<ClaudeIcon />} href="https://claude.ai/directory/37153cd7-b17c-470e-8b46-007e2859e0f3" horizontal />

    <Steps>
      <Step title="Add">
        Add Context7 from the Claude directory.
      </Step>
      <Step title="Sign in">
        Sign in to Context7 when Claude asks.
      </Step>
    </Steps>

    The connector also works in Claude Code when you sign in with the same Claude account. To use the Claude Code plugin instead, run `/plugin install context7@claude-plugins-official`.
  </Tab>
  <Tab title="ChatGPT" icon={<OpenAIIcon />}>
    <Card title="Add to ChatGPT" icon={<OpenAIIcon />} href="https://chatgpt.com/plugins/plugin_asdk_app_69ef18c674308191a2f952431f91ea61" horizontal />

    <Steps>
      <Step title="Install">
        Install the plugin from the ChatGPT plugin directory.
      </Step>
      <Step title="Sign in">
        Sign in to Context7 when ChatGPT asks.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Codex" icon={<OpenAIIcon />}>
    <Steps>
      <Step title="Add the plugin">
        ```bash
        codex plugin marketplace add upstash/context7
        codex plugin add context7@context7-marketplace
        ```
      </Step>
      <Step title="Sign in">
        Log in to Context7 in the browser window that opens. Then start a new Codex thread so Codex loads the plugin.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Cursor" icon={<CursorIcon />}>
    <Card title="Add to Cursor" icon={<CursorIcon />} href="https://cursor.com/marketplace/upstash/context7" horizontal />

    <Steps>
      <Step title="Install">
        In the Cursor Marketplace, select **Install** and choose a user or project scope.
      </Step>
      <Step title="Sign in">
        When the `context7` MCP server shows **Needs authentication**, click it and sign in.
      </Step>
    </Steps>
  </Tab>
  <Tab title="VS Code" icon={<VSCodeIcon />}>
    <Card title="Add to VS Code" icon={<VSCodeIcon />} href="https://marketplace.visualstudio.com/items?itemName=Upstash.context7-mcp" horizontal />

    <Steps>
      <Step title="Install">
        Install **Context7 MCP Server** from the Visual Studio Marketplace. It requires VS Code 1.101 or later.
      </Step>
      <Step title="Check">
        Run the **MCP: List Servers** command and check that Context7 is listed.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Other" icon="plug">
    Run the setup command. It finds the agents on your machine and configures Context7 for each one.

    ```bash
    npx ctx7 setup
    ```

    Or add the MCP server URL to your client. See [All MCP Clients](/resources/all-clients) for each client's config.

    ```txt
    https://mcp.context7.com/mcp
    ```
  </Tab>
</Tabs>
