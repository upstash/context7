---
title: Columns
description: Arrange content in a responsive grid
---

Set `cols` to the number of columns. The default is 2. Values above 4 also work. `<CardGroup>` is the legacy name for `<Columns>`.

## Usage

```mdx
<Columns cols={2}>
  <Column>First column.</Column>
  <Column>Second column.</Column>
</Columns>
```

Cards do not need a `<Column>` wrapper.

## Example

<Columns cols={2}>
  <Column>First column.</Column>
  <Column>Second column.</Column>
</Columns>
