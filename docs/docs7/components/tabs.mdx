---
title: Tabs
description: Switch between related blocks of content
---

Each `<Tab>` needs a `title`.

## Usage

```mdx
<Tabs>
  <Tab title="npm">npm install my-package</Tab>
  <Tab title="pnpm">pnpm add my-package</Tab>
</Tabs>
```

A tab can also have `icon` and `iconType` props.
