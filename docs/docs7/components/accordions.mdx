Use `<AccordionGroup>` when several accordions belong together.

## Usage

```mdx
<AccordionGroup>
  <Accordion title="Does Docs7 support MDX?">
    Yes.
  </Accordion>
  <Accordion title="Is this open by default?" defaultOpen>
    Yes.
  </Accordion>
</AccordionGroup>
```

`<Accordion>` also accepts `description`, `icon`, and `iconType`.
