---
title: Updates
description: Build a changelog from dated entries
---

`<Update>` requires a `label`.

## Usage

```mdx
<Update label="2026-08-24" tags={["New"]}>
  Added branch previews.
</Update>
```

`description` adds short text beside the label on narrow screens and below it on wide screens. Readers can filter entries by `tags`.

## Example

<Update label="2026-08-24" tags={["New"]}>
  Added branch previews.
</Update>
