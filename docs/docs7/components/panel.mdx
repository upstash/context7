title: Panel
description: Place custom content in the right column
---

A top-level `<Panel>` replaces the table of contents for that page.

## Usage

```mdx
<Panel>
  <Card title="Need help?" href="/support">
    Contact the support team.
  </Card>
</Panel>
```

If a page has more than one top-level panel, Docs7 merges them into one. When a page has a panel, request and response examples stay inline in the page.

## Example

See the panel in the right sidebar. On narrow screens, the panel is hidden.

<Panel>
  <Card title="Need help?" href="/docs7/quickstart">
    Open the Docs7 quickstart.
  </Card>
</Panel>
