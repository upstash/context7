---
title: Visibility
description: Show different content to people and AI tools
---

Use `for="humans"` or `for="agents"`.

## Usage

```mdx
<Visibility for="humans">
  This appears on the website.
</Visibility>

<Visibility for="agents">
  This appears in the Markdown export.
</Visibility>
```

## Example

<Visibility for="humans">
  This content is visible on the website.
</Visibility>

<Visibility for="agents">
  This content is visible only in the Markdown export.
</Visibility>
