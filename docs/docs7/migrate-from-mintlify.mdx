---
title: Migrate from Mintlify
description: Move an existing Mintlify project to Docs7
---

Docs7 reads the Mintlify content format. Keep your `docs.json` or `mint.json`, MDX pages, assets, snippets, redirects, and OpenAPI files.

## 1. Preview the project

From the folder that contains `docs.json` or `mint.json`, run:

```bash
npm install -g @upstash/docs7
docs7 dev
```

Open [http://localhost:3000](http://localhost:3000), or the address that the command prints, to see your documentation site.

## 2. Connect the repository

In your Context7 teamspace:

1. Open **Docs7** and click **Add New Site**.
2. Connect GitHub if needed.
3. Choose the repository and production branch.
4. Set **Docs path** to the folder that contains `docs.json`. Use `.` when it is at the repository root.
5. Publish the site.

<Frame>
<img src="/images/docs7/publish-a-site.png" alt="Publish a site in Docs7"></img>
</Frame>

Your Mintlify deployment stays online until you move the domain.

## 3. Move the domain

If you use a custom domain, add it to the Docs7 site. Docs7 shows the DNS records it needs. Add the `TXT` records, then change the `CNAME` to Docs7. Docs7 issues the HTTPS certificate a few minutes after the `CNAME` points at Docs7.

See [Custom Domains](/docs7/custom-domains) for each record and for serving the docs from a path.

<Frame>
<img src="/images/docs7/custom-domain.png" alt="Configure a custom domain in Docs7"></img>
</Frame>

After the switch, remove the Mintlify GitHub integration so one push does not deploy to both services.

## Custom CSS

Docs7 loads the `.css` files in your docs folder on every page. It puts Mintlify's published [ID and class selectors](https://www.mintlify.com/docs/customize/custom-scripts) on the matching elements, so a stylesheet written for Mintlify keeps working.

Docs7 has no element for the selectors below, so rules that use them have no effect:

- IDs: `#body-content`, `#mobile-nav`, `#mobile-nav-content`, `#api-playground-input`, `#endpoints-menu-trigger`, `#ask-assistant-code-block-button`, `#code-snippet-feedback-*`, `#feedback-form*`, `#page-context-menu*`, `#text-selection-tooltip*`, `#localization-select-*`, `#changelog-filters*`, `#multi-view-dropdown`
- Classes: `.sidebar-nav-group-divider`, `.option-dropdown`, `.tree-folder`, `.tree-file`, `.directory*`, `.login-link`, `.logout-link`, `.contextual-feedback-*`, `.code-snippet-feedback-*`, `.chat-assistant-floating-input`, `.chat-assistant-payload-item`, `.starter-question-text`

On small screens the navigation drawer is `#sidebar`. Generated API pages have no `#content`, because their body can hold several MDX blocks.
