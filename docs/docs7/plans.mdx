Docs7 is free to start. A Free teamspace can host up to three documentation sites with most Docs7 features, including the Context7 Agent. Pro adds private repositories and unlimited AI use.

| Feature | Free | Pro |
| --- | --- | --- |
| Price | $0 | $200 / month |
| Sites | 3 | 3 included, $200 / month for each additional site |
| **For agents** | | |
| [Markdown pages, `llms.txt`, and an Agent Skill](/docs7/agent-readiness) | ✓ | ✓ |
| Automatic [Context7](/overview) library updates | ✓ | ✓ |
| [Ask endpoint and WebMCP](/docs7/agent-readiness) | ✓ | ✓ |
| [AI Visibility and analytics](/docs7/ai-visibility) | 7-day history | 90-day history |
| [Context7 Agent](/docs7/agent) | Limited usage | Unlimited |
| [PR Review Agent](/docs7/agent#pr-review-agent) | Limited usage | Unlimited |
| [Code Watch Agent](/docs7/agent#code-watch-agent) | Public repositories, limited usage | Unlimited, private repositories too |
| **For people** | | |
| [Custom domain](/docs7/custom-domains) | ✓ | ✓ |
| API playground | ✓ | ✓ |
| AI chat assistant | Limited usage | Unlimited |
| [Feature requests](/docs7/feature-requests) | ✓ | ✓ |
| **For your team** | | |
| [Mintlify compatible](/docs7/migrate-from-mintlify) | ✓ | ✓ |
| [Preview deployments](/docs7/builds) for each pull request | ✓ | ✓ |
| [CLI deploys](/docs7/cli) | ✓ | ✓ |
| Private repositories | — | ✓ |
| Team support | — | ✓ |
| SOC 2 certified | — | ✓ |

"Limited usage" is a monthly allowance for each site. It resets at the start of each month. When a site uses its allowance, the agent or assistant stops for that site until the reset.

Free sites show a **Built with Docs7** link in the footer.

## Upgrade and downgrade

The teamspace owner changes the plan on the [Docs7 page](https://context7.com/docs7). When you downgrade to Free, you choose up to three public sites to keep. Docs7 removes the other sites. The current build of each site that you keep stays online.

Docs7 plans are separate from [Context7 plans](/plans-pricing).
