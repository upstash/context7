---
title: Docs7 configuration
description: Configure Docs7-only fields in docs.json
---

Docs7 supports the Mintlify `docs.json` format. It also adds `filterSidebar` at the top level and `productGroups` on navigation tabs.

## Filter the sidebar

Set `filterSidebar` to `true` to add a filter above the sidebar. Readers can press `/` to focus it.

```json docs.json
{
  "filterSidebar": true
}
```

The default value is `false`.

## Group products

Add `productGroups` to one navigation tab in each navigation scope. This tab owns the product switcher. Its `pages` or `groups` are the initial sidebar. Each product has its own `pages` or `groups`.

```json docs.json
{
  "navigation": {
    "tabs": [
      {
        "tab": "Documentation",
        "pages": ["index"],
        "productGroups": [
          {
            "group": "Products",
            "products": [
              {
                "product": "Redis",
                "icon": "/images/redis.svg",
                "description": "Serverless Redis",
                "pages": ["redis/overview", "redis/get-started"]
              }
            ]
          },
          {
            "group": "Utility",
            "products": [
              {
                "product": "Rate Limit",
                "pages": ["ratelimit/overview", "ratelimit/get-started"]
              }
            ]
          }
        ]
      },
      {
        "tab": "API Reference",
        "pages": ["api/introduction"]
      }
    ]
  }
}
```

In this example:

- `Documentation` owns the product groups. Its `index` page is the initial sidebar.
- `Redis` and `Rate Limit` each own their pages.
- `API Reference` stays in the top navigation.

A product must contain `pages` or `groups`, but not both. The arrays must not be empty. Product and group names must be unique within the owning tab.

If `productGroups` is not set, Docs7 uses your regular Mintlify navigation.
