An admin connects a Notion workspace under **Settings → Integrations** and chooses content from **Add → Notion**. A selected page includes its accessible child pages and the rows of nested databases. A selected data source includes its rows, each indexed as a separate page.

## Set up the connection

<Steps>
  <Step title="Create an internal connection">
    In the [Notion developer portal](https://www.notion.so/profile/integrations), create an internal connection for your workspace. Enable **Read content** and copy the connection token.
  </Step>
  <Step title="Share the content">
    In Notion, open each approved page or database and use **••• → Connections** to add the connection. You can also grant access from the connection's **Content access** tab.
  </Step>
  <Step title="Connect Context7">
    Open **Settings → Integrations → Notion**. Paste the token, choose **Test connection**, then **Connect**. The test shows the bot, workspace when available, and up to 10 accessible items. Context7 stores the token encrypted and displays only its last four characters.
  </Step>
</Steps>

Use an internal connection so workspace admins can choose what it sees. Personal access tokens and public OAuth connections are not supported.

## Add a library

Open **Add → Notion**, select pages and data sources, enter a title, and add the library. If a database contains several data sources, select the ones you want to index. Preview and picker results can lag after sharing; refresh the list if an item is missing.

The default limit is 10,000 pages per library. Set `NOTION_MAX_PAGES` on the Enterprise server to change the limit. Notion also caps each data source query at 10,000 rows. If a selection exceeds either limit, choose a smaller set of pages or data sources.

## Sync and monitor libraries

The default schedule is daily at 03:00 in the server timezone. Change or disable it under **Settings → Integrations → Notion**, or choose **Sync all now**. From a library, choose **Refresh** to sync it alone, or **Re-index all pages** to rebuild it.

Context7 lists the selected content each time. It checks page and block edit timestamps to skip Markdown retrieval, extraction, and embedding for unchanged pages. It still reads the block tree to find child pages and databases, since Notion search can omit accessible items. Deleted, trashed, or unshared content leaves the index after a successful listing. If a page fails to load or extract, its last indexed version remains available where possible. A failed listing leaves the live library in place. Failed library syncs retry after 15 minutes, 1 hour, and 6 hours.

The Notion card shows the last sync, unavailable selections, and failed pages. Open a failed page in Notion to check access, or export all failures as CSV.

## Authority labels

Use the title path inside the selection to match authority labels, for example `Quality/Release checks/Console`. Search results link to their original Notion pages.

## Network and rate limits

Allow outbound HTTPS to `api.notion.com`. For a trusted proxy, set `NOTION_API_URL` to its Notion API base URL, including `/v1`.

At one Markdown request per page, downloading 10,000 pages takes at least 56 minutes at 180 requests per minute or 17 minutes at 600 requests per minute. Discovery requests, long pages, extraction, embedding, and retries add time. With roughly one child listing per page as well, the API lower bounds are about 111 and 33 minutes respectively. Large hierarchies can require additional calls. Notion throttles data source queries separately.

Context7 defaults to 180 requests per minute. On Notion Business or Enterprise, set `NOTION_REQUESTS_PER_MINUTE=600` to use the higher budget. Other integrations can still exhaust a workspace's shared budget. See [Notion's request limits](https://developers.notion.com/reference/request-limits).

## Troubleshooting

- **Nothing appears in the picker:** Check the connection has **Read content** and is attached to the page or database. Refresh the picker after sharing.
- **The token was rejected:** Paste a current internal connection token from the intended workspace. Rotate a token by saving a replacement for the same connection.
- **The library says the connection changed:** Add the library again using the new connection and review the selections.
- **A sync reports too many pages:** Select fewer roots or data sources. The existing index remains available when the listing cannot complete.
