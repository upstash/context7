<Update label="2026-09-17" description="v1.3.9">

### Added

- Added native AWS Bedrock support for Anthropic Claude inference, Amazon Titan embeddings, reranking, and source-code documentation.

### Changed

- The server now requires a valid `LICENSE_KEY` and exits on startup without one.
- The setup wizard now defaults to the `gemini-3.7-flash` model.
- Parse failures now show clearer details, including GitLab-specific messages when a token is missing.

</Update>

<Update label="2026-09-08" description="v1.3.8">

### Added

- Added on-premise setup to the Context7 CLI: `ctx7 setup --mcp --base-url` configures MCP clients for your deployment, with a guided two-step API key flow and optional client-native configuration.

### Changed

- Parse logs no longer show per-file token counts, model names, LLM cost, or internal parser details.

</Update>

<Update label="2026-08-11" description="v1.3.2">

### Added

- Added support for running the image as a non-root user.
- Added a Helm chart for Kubernetes deployments.
- Added settings for the maximum number of concurrent LLM requests and the LLM request timeout. Timed-out requests are now cancelled.

### Fixed

- Fixed source-code indexing on the on-premise image.
- A parse that extracts nothing now says why.

</Update>

<Update label="2026-08-04" description="v1.3.1">

### Added

- Added the option to cancel running and queued parse jobs.

### Changed

- The dashboard now disables actions that your role or the workspace permissions do not allow.
- Improved website crawler coverage.

### Fixed

- Fixed parsing of scp-style SSH repository URLs, such as `git@host:org/repo.git`.
- A short database outage no longer crashes every replica.

### Security

- Git tokens are now redacted from logs, error messages, and support bundles.
- Support bundle downloads are now admin-only by default.
- The LLM, embedding, and Git connection tests now require an admin once setup is complete.

</Update>

<Update label="2026-07-24" description="v1.3.0">

### Added

- Added library access control: restrict which libraries each user can query over the MCP server and the REST API, scoped to their single sign-on groups or to individual users, with a workspace-wide allow-by-default or restrict-by-default posture.
- Added namespace access rules that govern every library under a path, with rules on an individual library taking precedence over the longest matching namespace.
- Added an access audit log that records access-rule changes and blocked access attempts.
- Added support for running the on-premise image as multiple replicas behind a load balancer, backed by a shared PostgreSQL database and a shared vector store.

### Changed

- Improved reranking for queries with several requirements, and reduced duplicate snippets in responses.

</Update>

<Update label="2026-06-24" description="v1.1.0">

### Added

- GitOps declarative repository management: define the repositories to index in a Git manifest (`repos.yaml`) and have Context7 reconcile them on startup, on a schedule, on manual trigger, and on GitHub push webhooks. Supports per-repo branch, folder, and file filters, plus pruning of repositories removed from the manifest.
- Generic OIDC single sign-on for the on-premise dashboard.
- Configure a GitHub Enterprise Server host from the dashboard so the GitHub App and tokens target your own server instead of github.com.

</Update>
